# 🎓 Decentralized Academic Certificate QR-Based Verification System

## 📌 Overview
This project is a blockchain-based system designed to verify academic certificates using QR codes. It ensures authenticity, prevents forgery, and provides secure validation.

## 🚀 Features
- QR code-based certificate verification  
- Blockchain-powered security  
- Tamper-proof academic records  
- Fast and reliable verification system  

## 🛠️ Tech Stack
- Frontend: React.js  
- Backend: Node.js,Flask Python  
- Blockchain: Ganache (Ethereum)  
- Tools: Truffle
- Database:MongoDb
